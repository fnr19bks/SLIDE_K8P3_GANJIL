Definisi

Apa Itu Algoritma?

Algoritma = kumpulan langkah logis dan berurutan untuk menyelesaikan masalah atau mencapai tujuan.

🍜 Resep

Urutan langkah memasak yang tidak boleh dibolak-balik.

🛵 Rute Ojek

Aplikasi memilih jalan tercepat menuju tujuanmu.

🕗 Jadwal

Jam ke-1 harus selesai sebelum jam ke-2 dimulai.

Ciri-Ciri

5 Ciri Algoritma yang Baik

Jelas

Satu langkah, satu arti. Tidak membingungkan.

Berurutan

Dikerjakan sesuai urutan, tidak melompat.

Berhingga

Ada awal, ada akhir. Tidak jalan selamanya.

Efektif

Bisa benar-benar dikerjakan, bukan wacana.

Punya Hasil

Di akhir proses, ada output yang jelas.

Inti Materi

Dari Ide ke Langkah: 5 Tahap

1
Pahami Masalah

Apa tujuan, input, dan output-nya?

2
Pecah (Decompose)

Masalah besar → bagian kecil.

3
Susun Urutan

A harus sebelum B, bukan asal.

4
Tuliskan

Naratif, pseudocode, atau flowchart.

5
Uji & Perbaiki

Coba jalankan, tambal yang bolong.

Cara Menulis #1

Pseudocode (Kode Semu)

Mirip bahasa pemrograman, tapi tetap mudah dibaca manusia.

MULAI INPUT : (data / bahan yang dibutuhkan) PROSES : 1. ... 2. JIKA (syarat) MAKA ... JIKA TIDAK ... OUTPUT : (hasil akhir) SELESAI

Cara Menulis #2

Flowchart (Diagram Alir)

Mulai
OvalTerminal: mulai / selesai
Proses

Data
Jajaran GenjangInput / output
Belah KetupatKeputusan Ya / Tidak
➜
PanahArah urutan langkah

Contoh Konkret 1

Meminjam Buku di Perpustakaan

  1. Murid datang membawa kartu anggota.
  2. Petugas cek: kartu masih aktif?
  3. Jika tidak aktif → perpanjang kartu dulu.
  4. Jika aktif → pilih buku yang diinginkan.
  5. Petugas cek ketersediaan buku.
  6. Jika tersedia → catat data → buku diserahkan.

Contoh Konkret 1

Versi Pseudocode

MULAI INPUT : kartu anggota, judul buku PROSES : 1. Cek status kartu anggota 2. JIKA kartu tidak aktif MAKA tampilkan "Perpanjang kartu" JIKA TIDAK lanjut ke langkah 3 3. Cek ketersediaan buku 4. JIKA buku tidak tersedia MAKA tampilkan "Coba judul lain" JIKA TIDAK catat peminjaman (judul, tgl pinjam, tgl kembali) OUTPUT : buku diserahkan + catatan peminjaman SELESAI

Contoh Konkret 2

Izin Masuk Laboratorium Komputer

  1. Murid meminta izin ke guru pengampu.
  2. Guru cek jadwal praktik jam tersebut.
  3. Tidak ada jadwal → izin ditolak.
  4. Ada jadwal → cek kelengkapan (sepatu, alat tulis).
  5. Belum lengkap → murid melengkapi dulu.
  6. Lengkap → masuk lab dan isi buku penggunaan.

✏️ Tugas: gambarkan versi ini dalam bentuk flowchart.

Cooperative Learning

Aktivitas Kelompok (3–4 Orang)

Pilih satu masalah sehari-hari di sekolah:

🧹 Piket Kelas

Siapa, kapan, dan mengerjakan apa.

📋 Absensi Harian

Dari daftar hadir sampai rekap.

⚽ Peminjaman Alat Olahraga

Dari permintaan sampai pengembalian.

🎯 Pendaftaran Ekstrakurikuler

Dari formulir sampai pengumuman.

Tugas Kelompok

4 Langkah Kerja

  1. Tentukan input dan output masalah.
  2. Susun langkah naratif terlebih dahulu.
  3. Ubah ke pseudocode atau flowchart.
  4. Cek dengan 5 ciri algoritma baik.

Checklist

Kriteria Algoritma yang Baik

  • Apakah setiap langkah jelas, tidak ganda arti?
  • Apakah urutannya logis, tidak melompat?
  • Apakah tidak ada langkah sia-sia?
  • Apakah ada titik akhir yang jelas?

Cek dulu sebelum dikumpulkan! ✅

Rangkuman

Poin Penting Hari Ini

  • Algoritma = langkah logis yang berurutan.
  • 5 tahap: Pahami → Pecah → Susun → Tulis → Uji.
  • Ditulis sebagai pseudocode atau flowchart.
  • Ciri baik: jelas, urut, berhingga, efektif, ada hasil.

Refleksi & Tindak Lanjut

Sebelum Kita Tutup

• Apa hal baru yang kamu pahami?
• Bagian mana yang masih sulit?
• Apa peranmu di kelompok tadi?

Tindak Lanjut

• Rapikan flowchart kelompok.
• Buat 1 algoritma rute rumah → sekolah.
• Kumpulkan pertemuan berikutnya.
